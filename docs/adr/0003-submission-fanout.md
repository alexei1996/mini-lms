# ADR 0003: Сдача пишется в архив, ведомость и Telegram

Date: 2026-11-18
Status: accepted

Context:
Сайт на GitHub Pages не хранит ответы. Учитель хочет и полный разбор работы, и таблицу, и короткий сигнал. Рассматривались три варианта: только база и страница учителя; только Google-таблица и Telegram; все три сразу.

Decision:
Каждая сдача сохраняется целиком в Supabase. Это архив. Оттуда учитель открывает ответы. В Google-таблицу добавляется строка ведомости. В Telegram учителю уходит одно сообщение. Ведомость и Telegram архив не заменяют.

Consequences:
Нужны проект Supabase, таблица Google и чат Telegram. Секреты Google и Telegram нельзя класть в код сайта: копирование делает сервер после записи в архив, не браузер ученика. Если один из трёх каналов недоступен, судьбу сдачи надо определить отдельно (сейчас открыто): работа уже в архиве не должна теряться из-за сбоя таблицы или Telegram. На бесплатном плане Supabase проект засыпает после недели без визитов; перед занятием его может понадобиться разбудить.
