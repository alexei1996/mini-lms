# ADR 0008: Ведомость дописывает сценарий Google

Date: 2026-11-23
Status: accepted

Context:
Строка ведомости должна появляться, когда компьютер учителя выключен. Сайт на GitHub Pages сам файлы не хранит и не может держать пароль Google. Рассматривались сценарий при Google-таблице и постоянная база Supabase, которая принимала бы сдачу и копировала строку в таблицу.

Decision:
К таблице подключён сценарий Google. После «Проверить» сайт отправляет ему имя и балл. Разрешение на запись хранится в сценарии, не в репозитории. Адрес сценария лежит в коде сайта. Кто прочитает код, может отправить строку от любого имени и с любым баллом, не открывая тест. Обычный проход по сайту этот адрес не показывает. Полный архив ответов и Telegram в эту работу не входят.

Consequences:
Нужны одна Google-таблица и один развёрнутый сценарий. Поддельная строка возможна только после чтения кода. Если сценарий не ответил, ученик всё равно видит балл, а строка нигде не сохраняется. Бесплатный Supabase для ведомости не нужен.
