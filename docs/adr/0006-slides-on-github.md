# ADR 0006: Опубликованные слайды — картинки в репозитории сайта

Date: 2026-11-19
Status: accepted

Context:
Ученик открывает сайт на GitHub Pages с другого компьютера, без общей сети. Рассматривалось отдельное хранилище Supabase для картинок слайдов. Учитель выбрал GitHub: по публикации туда уходят картинки, а приложение их показывает. Исходный PowerPoint или PDF ученику не отдаётся.

Decision:
Кнопка «Опубликовать» копирует картинки слайдов в файлы сайта и отправляет их в репозиторий GitHub. Черновики остаются в локальной папке `data` и в репозиторий не попадают. Кнопки «Скачать» нет.

Consequences:
Картинку, которую браузер показал, ученик может сохранить или сфотографировать. В публичном репозитории эти картинки тоже можно найти. Ключ теста с 2026-11-19 публикуется вместе с тестом (`docs/adr/0007-public-answer-key.md`). Новые сдачи GitHub Pages по-прежнему не хранит.
