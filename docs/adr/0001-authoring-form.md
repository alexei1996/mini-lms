# ADR 0001: Тесты собираются в авторской форме

Date: 2026-11-18
Status: accepted

Context:
Учитель хочет сам добавлять тесты: произвольное число вариантов, формулы, начертание текста и картинки (в том числе картинка как вариант ответа). Гайд предлагал описывать лабораторные файлами `_lab.json` в репозитории и править их через агента.

Decision:
В первой версии учитель собирает и правит тест в форме в браузере. Агент не является обязательным шагом на каждый новый вопрос. Исходный PowerPoint ученику не отдаётся; ключ ответов не коммитится в публичный сайт.

Consequences:
Вопросы, картинки и ключ должны сохраняться туда, куда ученик не может записать свои данные и откуда он не читает чужие сдачи и правильные ответы. Одного GitHub Pages для этого мало. Свободная генерация картинки «по кнопке внутри формы» этим решением не принята.
