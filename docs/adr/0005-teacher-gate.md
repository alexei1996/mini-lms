# ADR 0005: Пароль только у учителя

Date: 2026-11-18
Status: accepted

Context:
Ученик называет себя сам, именем и почтой, без пароля. Проверить личность продукт не берётся. В авторской форме при этом лежит ключ ответов, а в списке сдач — чужие работы. Секретная ссылка без пароля рассматривалась и была отклонена: она остаётся в истории браузера и в пересланных сообщениях.

Decision:
Страницы учителя — вход по почте и паролю. Туда входят авторская форма, загрузка презентаций и просмотр сдач. Страницы ученика пароля не спрашивают. Ключ ответов и чужие сдачи на страницах ученика не отдаются.

Consequences:
Любой, у кого есть ссылка на курс, может отправить попытку под любым именем. Защита здесь про учителя и ключ, не про то, чтобы не пустить постороннего на тест. Пароль учителя и ключи сервисов в репозиторий не кладутся.
