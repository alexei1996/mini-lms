# ADR 0007: Ключ теста публикуется вместе с вопросами

Date: 2026-11-19
Status: accepted

Context:
Раньше ключ оставался только на компьютере учителя, чтобы страница ученика не показывала верные варианты. Учитель решил, что тест — средство самопроверки, а не контроль самостоятельности. Ученик на другом компьютере открывает GitHub Pages и должен видеть верные ответы в любой момент прохождения.

Decision:
Опубликованный каталог содержит отметку верного варианта. На странице теста такие варианты отмечены сразу. Кнопка «Проверить» считает балл в браузере по этому ключу, поэтому ссылка GitHub достаточна. Пароль учителя в репозиторий не кладётся. Если локальный сервер учителя запущен, попытка дополнительно записывается у него.

Consequences:
Любой, кто откроет каталог, увидит верные варианты. Это принято. Чужие сдачи и пароль учителя на публичный сайт не попадают.
