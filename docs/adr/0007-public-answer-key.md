# ADR 0007: Ключ теста публикуется вместе с вопросами

Date: 2026-11-19
Status: accepted

Context:
Раньше ключ оставался только на компьютере учителя, чтобы страница ученика не показывала верные варианты. Учитель решил, что тест — средство самопроверки, а не контроль самостоятельности. Ученик на другом компьютере открывает GitHub Pages и должен получить балл без отдельного сервера. Верный вариант на странице ему не показывают.

Decision:
Опубликованный каталог хранит отметку верного варианта, чтобы балл считался на GitHub Pages. Страница ученика эту отметку не показывает: после «Проверить» видны балл и то, на какие вопросы отвечено верно. Пароль учителя в репозиторий не кладётся. Если локальный сервер учителя запущен, попытка дополнительно записывается у него.

Consequences:
Любой, кто откроет каталог, увидит верные варианты. Это принято. Чужие сдачи и пароль учителя на публичный сайт не попадают.
