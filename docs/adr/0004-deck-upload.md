# ADR 0004: Презентацию учитель загружает файлом

Date: 2026-11-18
Status: accepted

Context:
Сначала презентации должен был собирать агент из присланных файлов. Учитель хочет добавлять уже готовые PowerPoint и PDF сам, через системное окно «Открыть» и выбор файла. Отдельный редактор слайдов он не просил. Ученик при этом не должен получать исходный файл.

Decision:
На страницах учителя есть выбор файла `.pptx` или `.pdf`. Выбранный файл загружается и хранится вместе с курсом. Ученик листает слайды по одному. Кнопки скачивания нет. Анимация и встроенное видео не обещаются.

Consequences:
Путь на диске учителя ученику недоступен: после выбора файла содержимое уходит в хранилище курса, иначе другая машина его не откроет. Преобразование PowerPoint и PDF в последовательность слайдов — отдельная работа со своими пределами (сложные эффекты пропадут). Черновик презентации ученик не видит, пока учитель не опубликует курсный материал.
