## What to build

Учитель нажимает «Опубликовать». Если изменились название или вопросы, следующая принятая попытка открывает новый лист. Старый лист со строками остаётся. Если название и вопросы те же, попытка дописывает прежний лист. Смена только переключателя «можно сдать ещё раз» тоже остаётся на прежнем листе. Черновик до публикации лист не меняет.

Имя листа — название курса и название теста. Если такое имя уже есть, к новому листу добавляется дата публикации.

## Acceptance

- [ ] Публикация с новым названием или изменёнными вопросами даёт новый лист, а старые строки остаются на старом
- [ ] Публикация без таких изменений дописывает прежний лист
- [ ] Смена только переключателя повтора не открывает новый лист
- [ ] Сохранение черновика не открывает новый лист
- [ ] Занятое имя листа получает дату публикации
- [ ] Тесты `gradeEdition` и `continuesSheet` покрывают эти случаи без живой Google-таблицы
