# 04 — Авторская форма и тест без ключа

Status: ready-for-agent
Blocked by: 02
Spec: docs/work/specs/2026-11-18-course-presentations-and-tests.md

## What to build

Вошедший учитель собирает тест в авторской форме. У вопроса — текст из фрагментов (обычный, жирный, курсив, список, формула), своё число вариантов и не меньше двух. Вариант — текст, картинка или оба. Хотя бы один вариант отмечен верным. Переключатель «можно сдать ещё раз» у нового теста включён, учитель может его выключить.

Тест публикуется отдельно. Черновик ученик не видит. На опубликованном тесте ученик видит вопросы и может отметить любое число вариантов. Страница не показывает, какой вариант верный. Отправка ответов и балл в этот тикет не входят: их делает тикет 05.

Картинка варианта — файл, который учитель загружает. Кнопки «сгенерировать картинку» нет.

## Acceptance

- [ ] Учитель задаёт число вариантов, формулу, жирный или курсив и загружает картинку как вариант
- [ ] Тест с одним вариантом или без единого верного опубликовать нельзя
- [ ] У нового теста повтор включён, и выбор учителя сохраняется
- [ ] Черновик теста по ссылке курса не виден
- [ ] После публикации ученик видит вопросы и отмечает несколько вариантов, без пароля
- [ ] На странице ученика нельзя узнать верный вариант
- [ ] Тесты `toStudentTest`: в данных для ученика нет признака верного варианта
