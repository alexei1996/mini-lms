# 01 — Страница курса и листание слайдов

Status: done
Blocked by: none
Spec: docs/work/specs/2026-11-18-course-presentations-and-tests.md

## What to build

Ученик открывает ссылку курса и видит название, список презентаций и список тестов. Если опубликованного ещё нет, он видит название и понятную пустую страницу, без ошибки.

Презентация в этом тикете уже лежит готовыми картинками слайдов, не файлом PowerPoint. Ученик открывает её и листает по одному слайду вперёд и назад. Кнопки «Скачать» нет, адрес исходного файла нигде не показан. Страницы на русском.

Загрузка файла, вход учителя и прохождение теста в этот тикет не входят.

## Acceptance

- [x] По ссылке курса видны название, список презентаций и список тестов
- [x] Курс без опубликованных материалов показывает пустое состояние, а не ошибку
- [x] Ученик переходит на следующий и на предыдущий слайд
- [x] На странице слайдов нет кнопки «Скачать» и нет адреса исходного файла
- [x] Текст страниц на русском
