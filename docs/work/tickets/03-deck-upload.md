# 03 — Загрузка PowerPoint и PDF

Status: done
Blocked by: 02
Spec: docs/work/specs/2026-11-18-course-presentations-and-tests.md

## What to build

Вошедший учитель добавляет презентацию через системное окно «Открыть»: файл `.pptx` или `.pdf`. Модуль `importDeck` превращает файл в слайды по порядку. Ученику достаются только эти слайды. Публичного адреса исходного файла нет.

Новая презентация — черновик. После «Опубликовать» ученик листает её так же, как подготовленные слайды из тикета 01. Файл другого типа учитель добавить не может. Анимацию и видео воспроизводить не нужно.

## Acceptance

- [x] Учитель выбирает `.pdf` и `.pptx` в окне «Открыть» и видит слайды по порядку
- [x] До публикации ученик этой презентации не видит
- [x] После публикации ученик листает слайды и не получает исходный файл
- [x] Файл другого типа отклонён, курс от этого не ломается
- [x] Тесты `importDeck`: одностраничный PDF даёт один слайд; PPTX из двух слайдов даёт два слайда по порядку; чужой тип отвергается
