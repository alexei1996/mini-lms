# 07 — Первая строка ведомости

Status: done
Blocked by: none

## What to build

Ученик проходит опубликованный тест и нажимает «Проверить», пока компьютер учителя выключен. В Google-таблице появляется лист этой редакции. На листе колонки «№», «ФИО», «Результат (N)» и «Дата»: номер строки, имя как его вписал ученик, целое число верных ответов и день со временем по Москве. N в заголовке — сколько вопросов в тесте.

Если сценарий не ответил, ученик всё равно видит балл. Пароль Google в репозиторий не входит.

## Acceptance

- [x] Первая принятая попытка создаёт лист и одну строку с четырьмя колонками
- [x] В «Результат (N)» записано целое число, а N совпадает с числом вопросов
- [x] Дата стоит по Москве и не берётся из часов ученика
- [x] Пустое имя строку не создаёт
- [x] Молчание сценария не прячет балл ученика
- [x] Тесты шва «редакция и строка» и подставки листа проходят без живой Google-таблицы
- [x] В репозитории нет пароля Google
