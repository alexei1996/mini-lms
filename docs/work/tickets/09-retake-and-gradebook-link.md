# 09 — Повтор и ссылка на ведомость

Status: ready-for-agent
Blocked by: 07
Spec: docs/work/specs/2026-11-23-gradebook.md

## What to build

У теста выключен повтор. Ученик с тем же именем сдаёт его второй раз, компьютер учителя при этом выключен. Сценарий отвечает отказом, второй строки на листе нет, ученик видит, что повтор закрыт.

На странице учителя одна ссылка «Ведомость» на всю таблицу. Она не повторяется внутри каждого теста. По тестам учитель переходит листами таблицы. На страницах ученика ссылки нет. Таблицу открывает только аккаунт Google учителя.

## Acceptance

- [ ] При выключенном повторе вторая сдача с тем же именем не добавляет строку
- [ ] Ученик видит отказ, а не новую строку
- [ ] То же имя после очистки пробелов считается тем же
- [ ] При включённом повторе вторая сдача добавляет строку со следующим номером
- [ ] Одна ссылка «Ведомость» есть на странице учителя и ведёт на всю таблицу
- [ ] Внутри теста такой ссылки нет, на страницах ученика её тоже нет
- [ ] Подставка листа подтверждает отказ и следующий номер без живой Google-таблицы
