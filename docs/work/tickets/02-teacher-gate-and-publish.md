# 02 — Вход учителя, черновик и публикация

Status: done
Blocked by: 01
Spec: docs/work/specs/2026-11-18-course-presentations-and-tests.md

## What to build

Учитель создаёт курс и получает ссылку, которую можно отдать ученику. Страницы учителя открываются только после входа почтой и паролем. Ученик по ссылке курса пароль не вводит.

Подготовленная презентация (картинки слайдов, как в тикете 01) может быть черновиком. Черновик по ссылке ученика не виден. После «Опубликовать» она появляется в списке и листается. Снятие с публикации снова прячет её от ученика.

Авторской формы и загрузки PowerPoint в этом тикете нет. Список тестов на странице курса уже есть и остаётся пустым, пока тест нельзя собрать.

## Acceptance

- [x] Учитель создаёт курс и получает ссылку для ученика
- [x] Без входа страницы учителя не открываются
- [x] После выхода страницы учителя снова закрыты
- [x] Черновик презентации отсутствует на странице ученика
- [x] После «Опубликовать» ученик видит презентацию и листает слайды
- [x] Ученик открывает курс без пароля
