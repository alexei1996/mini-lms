# Мини-LMS: курсы, презентации и тесты

Status: ready-for-agent

## Problem

Учителю нужен сайт, который ученик открывает по ссылке. Ученик смотрит готовые презентации и проходит тесты. Исходный PowerPoint или PDF ученик не получает. Тест учитель собирает сам в браузере. Сдача сохраняется так, чтобы учитель мог открыть ответы позже, увидеть строку с баллом в таблице и получить короткое сообщение.

Сайт на GitHub сам ответы не хранит. Ключ правильных вариантов нельзя отдавать ученику: иначе балл в браузере считается только вместе с утечкой ключа.

## Solution

У каждого курса своя ссылка. На странице курса две публикации: презентации и тесты. Черновик по ссылке не виден.

Учитель входит почтой и паролем. Он создаёт курс, загружает `.pptx` или `.pdf` через системное окно «Открыть», собирает тест в авторской форме и нажимает «Опубликовать» у каждого материала отдельно.

Презентация для ученика — это слайды по одному, вперёд и назад. Исходный файл по ссылке не отдаётся. Анимация и встроенное видео не воспроизводятся.

Тест состоит из вопросов с вариантами. Вариант — текст, картинка или оба. Ученик может отметить несколько вариантов на любом вопросе: по числу верных вариантов страница не подсказывает форму ключа. Перед отправкой ученик вписывает имя и почту.

Отправка уходит на сервер. Сервер сверяет выбор с ключом, пишет попытку в архив и возвращает ученику только «Отправлено» и балл вида «7 из 10». Затем сервер добавляет строку ведомости и шлёт одну строку в Telegram. Сбой ведомости или Telegram не отменяет уже записанную попытку.

Словарь: `docs/CONTEXT.md`. Закрытые решения: `docs/DECISIONS.md`.

## User stories

1. Как ученик, я хочу открыть курс по ссылке и листать слайды, чтобы смотреть презентацию без исходного файла.
2. Как ученик, я хочу пройти опубликованный тест и сразу увидеть «Отправлено» и балл, чтобы понять, засчитана ли сдача.
3. Как ученик, я хочу вписать имя и почту без пароля, чтобы сдать тест с телефона.
4. Как учитель, я хочу входить паролем, чтобы ключ и чужие сдачи не открывались по ссылке курса.
5. Как учитель, я хочу загрузить готовый PowerPoint или PDF через «Открыть», чтобы не собирать слайды заново.
6. Как учитель, я хочу собрать вопрос с формулой, начертанием, своим числом вариантов и картинками, чтобы выложить свой тест.
7. Как учитель, я хочу включить или выключить повтор у конкретного теста, чтобы тренировку и разовую работу различать при создании.
8. Как учитель, я хочу видеть полные ответы в архиве, строку в ведомости и сообщение в Telegram, чтобы не собирать сдачи вручную.
9. Как учитель, я хочу править опубликованный тест, не переписывая уже сохранённые попытки.

## Implementation decisions

Сайт — статические страницы на GitHub Pages. Опубликованные картинки слайдов лежат в репозитории и открываются вместе с сайтом. Исходный PowerPoint или PDF в репозиторий не входит. Архив сдач, вход учителя и ключ ответов — не в публичных файлах сайта. Ведомость — Google-таблица. Оповещение — Telegram. Секреты в репозиторий не попадают.

Язык страниц — русский. Курсов несколько, учитель один.

Страницы учителя доступны только при входе. Страницы ученика пароля не спрашивают и не содержат ключ, чужие попытки и адрес исходного файла презентации.

Курс появляется по ссылке сразу после создания. Пока нет опубликованных материалов, ученик видит название и пустой список. Порядок внутри списка презентаций и внутри списка тестов задаёт учитель.

Загрузка презентации вызывает `importDeck`. Наружу ученику отдаются только картинки слайдов по порядку. Исходный файл публичного адреса не имеет. Личную копию файла для учителя хранить можно.

Текст вопроса и текст варианта — документ из фрагментов (обычный текст, жирный, курсив, список, формула), а не произвольный HTML. У вопроса не меньше двух вариантов и хотя бы один верный. У варианта есть текст, картинка или оба.

`toStudentTest` отдаёт вопросы и варианты без признака верного ответа.

`scoreAttempt` считает балл без сети: один вопрос — одно очко, очко только при полном совпадении набора выбранных вариантов с ключом. Итог — пара «очки, сколько вопросов». Функция не нужна ученику в браузере.

`recordAttempt` выполняется на сервере, где есть ключ:

1. Имя и почта обязательны. Почта сравнивается без учёта регистра, пробелы по краям снимаются. В имени краевые пробелы снимаются, повторные пробелы внутри схлопываются.
2. Если у теста повтор выключен и попытка с этим именем, почтой и тестом уже есть, новая не записывается.
3. Номер попытки — сколько принятых попыток с этим именем, почтой и тестом, включая текущую.
4. В архив пишется снимок теста на момент сдачи: формулировки, варианты, что выбрано, какой вариант был верным, балл. Правка живого теста этот снимок не меняет. Признак верного варианта в ответе ученику не возвращается.
5. Ученик получает факт отправки, балл и число вопросов.
6. После успешной записи в архив сервер дописывает ведомость и шлёт Telegram. В обоих каналах одни и те же поля: время, курс, тест, имя, почта, балл, номер попытки.
7. Если архив не записал попытку, ученик балл не видит. Если архив записал, а ведомость или Telegram нет, попытка остаётся, ученик балл видит, у попытки в архиве стоит отметка сбоя для учителя.

Переключатель повтора у нового теста включён. Страницы «мои результаты» нет.

## Testing decisions (seams)

Четыре шва. Страницы через них ходят, но проверяется модуль, а не кнопки. У каждого шва в тестах есть подставка вместо живого сервиса.

| Шов | Интерфейс | Что фиксируют тесты |
|---|---|---|
| Подсчёт балла | `scoreAttempt(test, answers) → { score, total }` | Верный набор, лишний вариант, неполный набор, несколько верных, пустой ответ, чужой идентификатор варианта |
| Вид теста для ученика | `toStudentTest(test) → studentTest` | В результате нет признака верного варианта ни у одного варианта |
| Разбор файла | `importDeck(bytes, filename) → slides` | Одностраничный PDF даёт один слайд; PPTX из двух слайдов даёт два слайда по порядку; другой тип файла отвергается |
| Отправка | `recordAttempt(input) → { score, total, attemptNumber, sheet, telegram }` | Архив получает снимок с ключом; ответ ученику ключа не содержит; повтор выключен — вторая попытка отклонена; номер попытки растёт; сбой ведомости или Telegram не удаляет попытку и не прячет балл; пустые имя или почта отклоняются |

`scoreAttempt` и `toStudentTest` без сети и без базы. `importDeck` в тестах читает короткие файлы-образцы. `recordAttempt` в тестах пишет в подставку архива, ведомости и Telegram.

## Out of scope

- Трёхмерные лабораторные, каталог моделей, файл `.labres`.
- Псевдоним, PIN, журнал «код → фамилия», шифрование ответов ключом учителя.
- Расчётные задачи с числом и допуском (см. `docs/ROADMAP_POST_V1.md`).
- Редактор слайдов, кнопка генерации картинки, показ верных вариантов ученику, частичный балл.
- Учётная запись ученика и страница его прошлых сдач.
- Воспроизведение анимации и видео из презентации.
- Запрет снимка экрана.
